# 物理模型与数值方法

## 1. 单位制（约化 LJ 单位）

内部计算全部使用 Lennard-Jones 约化单位，令参考量为：

| 量 | 参考 | 约化单位 |
| --- | --- | --- |
| 长度 | σ | r → r/σ |
| 能量 | ε | U → U/ε |
| 质量 | 粒子质量 m（`species.mass`） | m → m/m_ref = 1 |
| 温度 | ε/k_B | T → k_B T/ε |
| 时间 | σ√(m/ε) | t → t/√(m/ε) |

代码中取 k_B = 1。以氩 (σ≈3.405 Å, ε/k_B≈119.8 K, m≈39.95 u) 为例，
1 个约化时间单位约为 2.16 ps。速度由 N(0, T/m) 的高斯分布给出。

## 2. 对势（截断平移 LJ）

```
U_LJ(r) = 4ε [(σ/r)^12 − (σ/r)^6]
U(r)    = U_LJ(r) − U_LJ(r_c)   for r < r_c, 否则 0
```

减去常数 U_LJ(r_c) 保证在截断半径 r_c（`cutoff`）处势能连续、可微。
对单组分体系 ε、σ 为全局配置；力由 F_i = −∂U/∂r_i 计算，牛顿第三定律成对累加。
要求 r_c < min(Lx, Ly, Lz)/2，以保证最小镜像约定成立（启动前强制校验）。

## 3. 周期性边界条件

三个方向均为立方体 PBC：每步漂移后将坐标折回 [0, L)；
成对位移用最小镜像 `Δ − L·round(Δ/L)`。同时维护一份“未折叠”坐标用于 MSD。

## 4. 积分器

### NVE — Velocity Verlet

标准两步蛙跳形式：`v(t+½)` → `r(t+dt)` → 重新算力 → `v(t+1)`。
每步仅一次力评估。无显式能量注入，长期能量漂移仅由浮点与截断离散误差产生。

### NVT — BAOAB Langevin（Leimkuhler–Matthews）

算子分裂 `B A O A B`：半步力踢 → 半步漂移 → OU 摩擦/噪声 → 半步漂移 → 半步力踢，
每步一次力评估。摩擦系数 γ（`thermostatFriction`），目标温度 T（`targetTemperature`）：

```
v ← a·v + √[T(1−a²)/m]·ξ,   a = e^{−γdt},   ξ ~ N(0,1)
```

高斯噪声由内置 SplitMix64 + Box–Muller 提供，RNG 单 64 位状态纳入检查点。
BAOAB 在 d→0（仅 O 步）时对位置采样为二阶准确，温度收敛稳健。

## 5. 观测量

- 瞬时温度：`T = 2K / (3N − 3)`（去除质心运动的 3 个约束）。
  K 由去质心速度计算；初始化时自动扣除质心平动。
- RDF：`g(r) = H(r) / [N·F·ρ·V_shell]`，H 为 F 帧中距离落在壳层内的
  无序对计数，ρ = N/V，V_shell = 4π/3·(r_o³ − r_i³)。上限 r 取
  `min(L_min/2, 1.8σ)`，默认 400 个箱。
- MSD：以初始（或续跑检查点恢复的）未折叠坐标为参考，
  `MSD(t) = (1/N) Σ_i |r_i^u(t) − r_i^u(0)|²`，按采样间隔记录前 128 个滞后点。

## 6. 确定性

- 所有随机性仅来自 NVT 噪声，使用单状态 SplitMix64 PRNG。
- 浮点运算遵循严格的“粒子主序 × x/y/z”累加顺序，元胞列表邻居遍历顺序固定，
  因此同输入同种子在同一 JVM/平台上逐位可复现。
- 检查点保存 RNG 状态、全部坐标/速度/力、未折叠坐标、MSD 参考与历史、
  RDF 直方图与帧数、历史样本；续跑在浮点层面与不中断运行完全一致。

## 7. 能量守恒（NVE 长期漂移）

Velocity Verlet 对总能量为有界振荡、零系统漂移的辛积分。
内置示例 `argon-fcc-nve`（108 粒子，ρ=0.8，dt=0.004，2000 步）实测：

- 每粒子端点能量漂移 |ΔE|/N < **5×10⁻⁴ ε**（自动化测试 `PhysicsConservationTest` 强制约束）；
- 相对总能量漂移 |ΔE|/|E| < **2×10⁻⁴**。

该界限适用于默认 dt=0.004 的示例配置；dt 增大会按 O(dt²) 放大误差。

## 8. 检查点与恢复

- 检查点格式：`{version, sha256, payload:{config,state}}`，
  SHA-256 覆盖 payload 的规范 JSON 文本，检测截断/篡改/磁盘损坏。
- 写入：临时隐藏文件 → `ATOMIC_MOVE`（文件系统不支持时退化为替换 move）→
  按保留数（`retainedCheckpoints`，默认 3）清理旧检查点。
- 恢复：按文件名（步数）从新到旧尝试，第一个校验通过者生效；
  全部损坏才报错。因此“最新损坏、回退更早有效检查点”是默认行为。
- 取消/超时/发散触发后，引擎仍会提交一次最终检查点，
  保证终止时最近状态可恢复；不会残留 `.tmp` 中间文件。

## 9. 复杂度与适用规模

| 规模条件 | 方法 | 单步复杂度 |
| --- | --- | --- |
| L_min ≥ 3·r_c | 均匀元胞列表（13 邻居半壳，扁平 CSR 数组） | O(N) |
| L_min < 3·r_c | 最小镜像直接遍历 | O(N²) |

实测（OpenJDK 17，本机，ρ=0.8，r_c=2.5，NVE，含一次力评估/步；
JIT 预热后，`mvn test -DrunBenchmarks=true`）：

| N | 约 ms/步 |
| --- | --- |
| 500 (5×5×5 FCC) | ~1.1 |
| 1372 (7³) | ~3.4 |
| 2048 (8³) | ~5.4 |

1372→2048（1.49× 粒子）单步耗时增长约 1.2–1.5×，拟合复杂度指数 < 1.3，
满足近线性（自动化 `ScalingBenchmarkTest` 约束，仅 `-DrunBenchmarks=true` 时运行）。

建议适用规模：元胞列表路径下 N ≲ 10⁴（内存与单核耗时均舒适）；
N ≲ 10³ 的小盒体系走 O(N²) 回退仍在亚毫秒量级。本服务为单进程单核计算，
不包含空间分解或 GPU，大规模 (≫10⁴) 不适用。
